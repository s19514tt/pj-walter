ピンイン声調 POC

録音 → Gemini で「聞こえたピンイン（声調付き）」と「漢字」を取得 → 本来あるべき声調と突き合わせる。
検証したいのは1点だけ： わざと声調を間違えたとき、モデルはその間違いを報告するか？（それとも正しい声調に丸めるか）

設定

キーは localStorage（この端末のこのブラウザ内）にのみ保存され、送信先は generativelanguage.googleapis.com だけです。共用PCでは保存しないでください。

実験モード

録音

0.0s

未録音。16kHz モノラル WAV に変換して送ります（アプリ本体と同じ形式）。

入れると「本来あるべき声調」をこの文から計算します。空なら認識された漢字から計算します。

実験タリー

0テイク
0検出できた
0見逃した
0誤検出
$0.0000合計コスト

判定の目安: わざと崩したテイク10本中7本以上で「検出できた」、正しく言ったテイクで誤検出2本以下 → そのモードは実用可能。
わざと崩したのに毎回「差分なし」なら、そのモードは音を聞かずに辞書引きしている＝実装しても無意味。
